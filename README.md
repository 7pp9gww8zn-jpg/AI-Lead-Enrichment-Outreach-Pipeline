# AI Lead Enrichment & Personalized Outreach Pipeline — Interactive Demo

**Live demo:** https://7pp9gww8zn-jpg.github.io/AI-Lead-Enrichment-Outreach-Pipeline/

Interactive proof-of-concept for a B2B cold-outreach automation pipeline (Clay + LLM + Instantly):

1. **Scrape** — domain, tech stack, hiring and funding signals
2. **Enrich** — persona, trigger event and case-study matching (Clay / LLM triage)
3. **Write** — 1-to-1 email, follow-up and LinkedIn copy with spam-word filtering
4. **Dispatch** — push to Instantly / Smartlead

Pick one of the four preset ICP leads and click **Run Deep Enrichment & Synthesis**.

> Demo only: companies, people, figures and emails are fictional sample data; nothing is scraped or sent.
